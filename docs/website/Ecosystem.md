# 🚀 `auraecosystem/awesome-ai-prompts`

Aura Ecosystem Official Repository

This repository will become the largest Prompt Engineering library in your ecosystem, integrated with Web4, LMLM, GPT-5-mini, KIBS, QUBUHUB, and Aura Playground.

* Import and translate all 49 prompts from the uploaded repository into English.

* Preserve original authors and attribution metadata.

* Convert prompts into Aura Prompt Card (`.md`) format.

* Categorize prompts into Web, UI/UX, Three.js, SVG, AI, Games, Video, Image, Crypto, etc.

* Create multilingual folders (`en`, `tr`, `zh`, `ja`, `ko`, `hi`, `fr`, `ar`).

## Phase 6 — SDK + CLI

Bash

```
npm install @aura/prompts
```

Bash

```
aura prompts search threejs
aura prompts run watch-luxury --provider lmlm
aura prompts translate watch-luxury --lang tr
```

JavaScript SDK:

TypeScript

```
import { PromptEngine } from "@aura/prompts";

const prompt = await PromptEngine.load("watch-luxury");

await prompt.run({
  provider: "gpt5-mini",
  variables: {
    product: "Aura Watch",
    framework: "Next.js 16"
  }
});
```
