# Awesome AI Prompts 🚀

A production-ready, multi-ecosystem prompt engineering repository optimized for **Web4 protocols**, **Local Multi-Language AI Models (LMLM)**, decentralized nodes, and modern developer workflows.

---

## 📂 Repository Structure

- `prompts/`: Curated, version-controlled prompts categorized by target engine (`lmlm`, `web4`, `blockchain`, `compiler`, etc.).
- `promptcards/`: Reusable, modular prompt components with structured frontmatter.
- `schemas/`: JSON schemas validating prompt definitions and metadata.
- `cli/` & `sdk/`: Developer tooling to parse, validate, and execute prompt pipelines.
- `docs/`: Comprehensive guides, handbooks, and architecture specs.
